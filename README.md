# MultiModule Microservices

این پروژه شامل چهار میکروسرویس است که به هم متصل می‌شوند و به ترتیب شامل سرویس‌های `Order`, `Payment`, `Shipping`, و `Notification` می‌باشد. هر سرویس یک endpoint دارد که در آن درخواست‌ها پردازش می‌شود و ارتباط بین سرویس‌ها از طریق **RestTemplate** برقرار می‌شود.

## ساختار پروژه

1. **Order Service**:
    - پردازش درخواست‌های سفارشات.
    - درخواست‌ها را به سرویس پرداخت ارسال می‌کند.

2. **Payment Service**:
    - پردازش پرداخت‌ها.
    - درخواست‌ها را به سرویس ارسال کالا (Shipping) ارسال می‌کند.

3. **Shipping Service**:
    - پردازش ارسال کالا.
    - درخواست‌ها را به سرویس نوتیفیکشن ارسال می‌کند.

4. **Notification Service**:
    - ارسال نوتیفیکشن‌ها پس از تکمیل فرآیند.

## پیش‌نیازها

- Java 11 یا بالاتر
- Maven برای مدیریت وابستگی‌ها
- Spring Boot برای پیاده‌سازی میکروسرویس‌ها
- Git برای مدیریت کدها
- Docker (اختیاری)
